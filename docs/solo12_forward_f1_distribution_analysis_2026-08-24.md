# Solo12 Forward F1 低跳分布分析

日期：2026-08-24

## 方法

- checkpoint：`c9600`、`c10200`、`c10800`
- 指令：`x=0.2 m`
- 协议：完整随机化、deterministic actor、observation noise `all`
- 样本：同一 `seed=441`，512 个环境，每环境一回合
- 配对校验：15 个主要物理随机参数在三个 checkpoint 间逐环境完全一致，最大差值均为 0
- 低跳定义：最大高度 `<0.5 m`

## 总体变化

| Checkpoint | 高度均值 | 高度达标率 |
|---|---:|---:|
| c9600 | 0.567 m | 77.5% |
| c10200 | 0.528 m | 68.0% |
| c10800 | 0.443 m | 17.8% |

`c9600` 达标而 `c10800` 低跳的配对样本为 306/512（59.8%）。退化不是 nominal 能力消失，而是整个随机化分布整体下移约 0.12 m。

## 主要低跳分布

### 1. 关节摩擦，最强因素

| 关节摩擦 | c9600 高度 | c10800 高度 | c10800 达标率 |
|---|---:|---:|---:|
| 0.0000-0.0107 | 0.637 | 0.485 | 51.6% |
| 0.0110-0.0206 | 0.585 | 0.455 | 15.6% |
| 0.0208-0.0312 | 0.545 | 0.428 | 3.9% |
| 0.0312-0.0400 | 0.503 | 0.406 | 0.0% |

`>0.02` 基本进入低跳区；`0.011-0.031` 是最明显的“原本能跳、后期变低”区间。

### 2. 延迟，高端点显著放大退化

| 初始采样延迟 | c9600 高度 | c10800 高度 | c10800 达标率 |
|---|---:|---:|---:|
| 0 ms | 0.581 | 0.459 | 22.5% |
| 0.1-4.3 ms | 0.600 | 0.470 | 32.5% |
| 4.4-20.6 ms | 0.563 | 0.434 | 13.3% |
| 20.8-45.0 ms | 0.528 | 0.412 | 3.9% |

最后一档的有效延迟由 history 上限裁到约 40 ms。高延迟在 c9600 已有影响，到 c10800 后明显放大。

### 3. 恢复系数，低恢复系数绝对高度最低

| 恢复系数 | c9600 高度 | c10800 高度 | c10800 达标率 |
|---|---:|---:|---:|
| 0.001-0.090 | 0.511 | 0.409 | 4.7% |
| 0.091-0.200 | 0.563 | 0.437 | 16.4% |
| 0.200-0.306 | 0.579 | 0.451 | 17.2% |
| 0.306-0.400 | 0.617 | 0.477 | 32.8% |

低恢复系数是固有困难角落，不完全是 c10800 新产生的问题；但它会显著放大全局高度下降。

### 4. Payload，次要因素

`payload >1.28 kg` 时，c10800 高度均值为 0.431 m、达标率 13.3%；`payload <-0.04 kg` 时为 0.456 m、25.0%。影响存在，但明显弱于关节摩擦、延迟和恢复系数。

## 典型组合

| 组合 | c9600 高度 | c10800 高度 | c10800 达标率 | 从达标变低跳 |
|---|---:|---:|---:|---:|
| 关节摩擦 0.0208-0.0312 + 恢复系数 0.200-0.306 | 0.574 | 0.443 | 3.0% | 93.9% |
| 关节摩擦 0.0110-0.0206 + payload 0.654-1.282 kg | 0.604 | 0.453 | 3.1% | 93.8% |
| 关节摩擦 0.0110-0.0206 + 延迟 20.8-45.0 ms | 0.553 | 0.425 | 0.0% | 82.5% |

## 不是主要因素

- 地面摩擦 `0.013-2.977`：四分位高度差仅 0.009 m。
- 关节阻尼 `0-0.010`：四分位高度差仅 0.010 m。
- COM xyz `±0.02 m`：各轴四分位高度差为 0.005-0.008 m。
- 电机强度均值：四分位高度差仅 0.003 m。
- link mass factor 总均值：四分位高度差仅 0.002 m。

## 结论与下一步

1. c10800 的问题是全分布起跳能力整体下降，不是 nominal 或单一角落失效。
2. 绝对低跳由关节摩擦、高延迟、低恢复系数依次放大；payload 为次要因素。
3. 不能据此直接修改 reward。下一步应从 c9600/c10800 做固定参数单变量扫描：优先关节摩擦，其次延迟和恢复系数；只有固定扫描复现差异后，才决定 reward 修复还是随机化课程修复。

## 固定单变量因果扫描

在其余随机化保持完整时，分别固定三个目标参数，256 环境、同 seed 配对：

| 因素 | 固定值 | c9600 高度 | c10800 高度 | 结论 |
|---|---:|---:|---:|---|
| 关节摩擦 | 0 / 0.02 / 0.04 | 0.654 / 0.577 / 0.488 | 0.479 / 0.447 / 0.397 | 高关节摩擦因果降低高度 |
| 延迟 | 0 / 20 / 40 ms | 0.594 / 0.578 / 0.535 | 0.466 / 0.422 / 0.402 | 高延迟因果降低高度 |
| 恢复系数 | 0 / 0.2 / 0.4 | 0.467 / 0.585 / 0.613 | 0.388 / 0.448 / 0.469 | 低恢复系数因果降低高度 |

该扫描只证明当前能力边界，不证明续训能否改善。

## 无 reward 修改的课程可训练性验证

三个分支均独立从 c9600 开始，不互相继承：

- mild 300 轮：关节摩擦 `[0,0.02]`；延迟 `[0,20] ms`；恢复系数 `[0.2,0.4]`。
- full 500 轮：分别恢复到 `[0,0.04]`、`[0,40] ms`、`[0,0.4]`。
- 每个分支总计 800 轮，reward 配置逐项不变。
- 最终用同一 seed 做 nominal、full 和对应困难端点配对验收。

| 分支 | 条件 | c9600 高度/达标/稳定 | c10400 高度/达标/稳定 | 结果 |
|---|---|---|---|---|
| 关节摩擦课程 | full | 0.577 / 84.0% / 39.8% | 0.496 / 47.7% / 18.8% | 明显退化 |
| 关节摩擦课程 | friction=0.04 | 0.488 / 50.4% / 29.3% | 0.418 / 0.0% / 0.0% | 端点退化 |
| 延迟课程 | full | 0.577 / 84.0% / 39.8% | 0.557 / 80.1% / 50.0% | 稳定改善、高度小幅退化 |
| 延迟课程 | latency=40 ms | 0.533 / 70.3% / 32.0% | 0.518 / 60.9% / 28.9% | 端点未改善 |
| 恢复系数课程 | full | 0.577 / 84.0% / 39.8% | 0.527 / 64.1% / 47.7% | 稳定改善、高度退化 |
| 恢复系数课程 | restitution=0 | 0.481 / 41.4% / 22.7% | 0.456 / 33.2% / 22.7% | 端点未改善 |

Nominal 三个分支仍保持 100% 高度成功，但高度均从 c9600 的 0.734 m 降到 0.591-0.674 m。由此可区分：随机化参数确实影响当前能力，但在当前 reward 下，单纯课程续训没有学会提高困难端点能力，而是重复选择较低、较安全的跳跃。

## 更新后的判断

1. 不能把困难端点表现差直接称为模型能力上限。
2. 已用三个独立、各 800 轮的训练分支证明：当前 reward 不变时，这三种课程续训均不能解决高度鲁棒性问题。
3. 延迟课程对 full 稳定性有收益，但没有提高 40 ms 端点，因此不能判为延迟鲁棒性训练成功。
4. 继续按原 reward 堆轮数没有证据支持，应暂停在 F1；下一步需要用户决定是否允许做最小 reward 因果修复。
